# Code of Conduct

kube-bmc follows the [CNCF Code of Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md).

Instances of abusive, harassing or otherwise unacceptable behavior can be reported by contacting
the project maintainers listed in [MAINTAINERS.md](MAINTAINERS.md). If the issue cannot be
resolved with the maintainers, it can be escalated to the CNCF as described in the code of
conduct.
