# Design proposals

Changes to the public API, to security-relevant behavior or to the project governance start with
a design proposal. Copy the template below into `NNNN-short-title.md`, open a pull request and
link it from the related issue.

| Number | Title | Status |
|---|---|---|
| [0001](0001-live-data-api.md) | Live hardware data through an aggregated API | Proposed |

## Template

```markdown
# NNNN: Title

- Status: Proposed | Accepted | Implemented | Rejected | Withdrawn
- Authors:
- Created:

## Summary
## Motivation
### Goals
### Non-goals
## Proposal
## Alternatives considered
## Compatibility and migration
## Security considerations
## Test plan
```
